THIRD-PARTY NOTICES

BlueHeighliner.MicroGate (the Core library) has no third-party runtime dependencies: it
references no NuGet packages, so no third-party license text needs to be reproduced for
binary redistribution.

The Tests project (xUnit, Moq, coverlet) and the Sample project (Avalonia, Microsoft.Extensions.DependencyInjection)
are not redistributed as part of the published package.

Keep this file in sync whenever Core gains a PackageReference (direct or transitive) whose
license requires its text and copyright notice to accompany binary redistribution.
